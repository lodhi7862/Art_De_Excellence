# Art De Excellence

Static website for the Art De Excellence haute joaillerie OEM/ODM studio.

## Local preview

Open `index.html` in a browser, or from this folder:

```bash
npx serve .
```

## Deploy on Vercel

1. Import this GitHub repository in [Vercel](https://vercel.com/new).
2. Framework Preset: **Other** (static HTML). Leave build settings empty.
3. Deploy. Vercel will serve `index.html` at the root.

No environment variables or build command are required.

## Pages

- `/` — main site (home, about, services, portfolio, blog, FAQ, contact)
- `/all-services` — detailed OEM service guide
